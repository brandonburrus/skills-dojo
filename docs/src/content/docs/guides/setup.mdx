## Configuration

Dojo works with zero configuration using sensible defaults. To customize behavior, create a `dojo.toml` in your project root:

```toml
[skills]
dir = ["skills", ".agents/skills"]

[model]
provider = "anthropic"
evaluator = "claude-haiku-4-5"

[reporting]
per-skill = true
consolidated = false
```

See the [Config Reference](/reference/config/) for the full schema.

## Global CLI flags

These flags apply to all commands and override `dojo.toml` values:

| Flag | Description |
|------|-------------|
| `--cwd <dir>` | Working directory for config and skill discovery |
| `--skills-dir <dir>` | Override skills directory (repeatable) |
| `--model-provider <provider>` | Override model provider |
| `--evaluator-model <model>` | Override evaluator model |

See the [Commands Reference](/reference/commands/) for all available commands and options.

## Model provider

Dojo uses a model provider to power the evaluator agent that runs your evals. Four providers are supported:

| Provider | Literal | API Key / Auth | Default Model |
|----------|---------|----------------|---------------|
| Anthropic | `anthropic` | `ANTHROPIC_API_KEY` | `claude-haiku-4-5` |
| OpenAI | `openai` | `OPENAI_API_KEY` | `gpt-4o-mini` |
| GitHub Copilot | `copilot` | Copilot subscription + auth | SDK default |
| Vercel AI SDK | `vercel` | Key for the underlying provider | `openai/gpt-4o-mini` |

The default provider is **Anthropic**. Switch providers via `dojo.toml` or the `--model-provider` CLI flag.

```toml
[model]
provider = "anthropic"
evaluator = "claude-haiku-4-5"
```

For the **Vercel** provider, the model string must be in the form `<underlying-provider>/<model-id>` (e.g. `openai/gpt-4o-mini` or `anthropic/claude-haiku-4-5`). This routes through the Vercel AI SDK to the specified underlying provider.

See the [Config Reference](/reference/config/#model-fields) for the full model configuration options.
